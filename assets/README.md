# 动画资源目录

把透明 PNG 动画帧放进对应目录，文件名按播放顺序排列，例如：

```text
assets/
├── idle/
│   ├── 000.png
│   └── 001.png
├── hover/
│   ├── 000.png
│   └── 001.png
└── hit/
    ├── 000.png
    └── 001.png
```

- `idle`：鼠标移开时的待机动画，默认 8 FPS
- `hover`：鼠标悬停时的动画，默认 10 FPS
- `hit`：点击小猫或按空格时的拍打电脑动画，默认 12 FPS

所有帧建议使用相同尺寸的透明 PNG。程序会自动按文件名排序，并将资源缩放到宠物窗口内。

如果目录没有 PNG，程序会自动使用内置绘制的小猫作为后备，不影响运行。
